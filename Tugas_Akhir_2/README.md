## 📖 Deskripsi Proyek
Repositori ini berisi dokumentasi dan *file* Tugas Akhir Praktikum Jaringan Komputer Modul 2. Praktikum ini mencakup dua bagian utama:

1. **Simulasi Jaringan (Cisco Packet Tracer)** 
   Pembuatan topologi jaringan dasar meliputi konfigurasi IP, VLAN 10 (Operations), VLAN 99 (Management), pengaturan *Access Port*, implementasi *Trunking* antar-switch, serta pengujian konektivitas (Ping).
2. **Praktikum Fisik (Crimping UTP)**
   Proses perakitan kabel jaringan fisik menggunakan kabel UTP, konektor RJ-45, tang crimping, dan pengujian kelayakan kabel menggunakan LAN Tester.
